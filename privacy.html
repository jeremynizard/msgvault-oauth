Privacy policy

This OAuth client is used solely by its owner, Jeremy Nizard, to archive his own Gmail account with msgvault.

Data accessed

Gmail messages, labels and attachments of the owner's own account, with read-only access.

How data is used and stored

Data is copied to a local archive stored only on the owner's computer, for offline search and archiving. The app operates no server and does not send data to the developer or to any third party. Data is never sold or used for advertising.

Google API Services User Data Policy

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from myaccount.google.com/permissions.
